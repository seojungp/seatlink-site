# Seatlink site

승인된 검정·시안·마젠타 디자인에 간결한 홈 구성, 가입 동선, 원화 중심 요금 비교를 적용한 시트링크 정적 사이트입니다.

## 실행

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

기존 로컬 서버 주소는 `http://127.0.0.1:8765/index.html`입니다.

## 구성

- 홈: 좌석 선택 미리보기, 특징 띠, 단계별 이용 안내, 다운로드 안내, FAQ
- 좌석: 사양·프레임 필터, 조건에 맞는 추천, 선택 좌석·프레임·충전 요금제 전달
- 충전: 금액·프레임에 따른 이용 시간과 시간당 원화 환산 금액, 지원하지 않는 좌석 프레임 선택 방지
- 홈에는 금액·포인트 수치·요금표를 노출하지 않으며 상세 요금은 로그인 없이 `charge.html`에서 확인
- 계정: 로그인·회원가입 시안 화면, 입력 정보 전송·저장 없음
- 기존 내 좌석·포인트 이력·입금확인·공지사항·개인정보처리방침은 유지하고 같은 디자인으로 통일
- 13개 HTML과 `assets/`의 CSS·JavaScript·이미지로 구성
- 기존 부가 화면에서 사용하는 `app.js`는 유지. 이전 `style.css`, `modern.css`, 기타 JavaScript는 호환용으로 보존

## 계산 기준

- 이용 가능 시간: `floor(총 포인트 / 10분당 포인트) × 10분`
- 시간당 환산 금액: `충전 금액 / 이용 가능 시간(시간 단위)`를 원 단위로 반올림
- 예: 30,000원 충전, 37,200P, 144프레임(250P/10분)은 24시간 40분, 시간당 약 1,216원
- 좌석·사양·요금은 디자인 시안용 예시

## 배포

기존 GitHub Pages 저장소 `seojungp/seatlink-site`의 `main` 루트에서 배포합니다.
기존 `CNAME`(`seatlink.kr`), `.nojekyll`, `robots.txt`를 유지합니다.

## 시안 범위

로그인·가입·결제·접속기 다운로드·원격 접속·문의 접수는 실제 시스템에 연결되지 않았습니다.
모든 게임을 이용할 수 있다는 서비스 안내에 맞춰 게임별 목록·검색·지원 여부 문의 동선을 제거했습니다.
이용 과정에 보이는 접속 화면은 실제 접속기 캡처가 아닌 설명용 예시입니다.
외부 폰트가 로드되지 않으면 시스템 글꼴을 사용합니다.
